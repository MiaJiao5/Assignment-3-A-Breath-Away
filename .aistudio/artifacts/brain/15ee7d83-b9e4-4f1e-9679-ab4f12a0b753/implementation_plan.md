# 《短暂漫游 (Brief Roaming)》实现方案

《短暂漫游 (Brief Roaming)》是一款主打“喷枪柔焦与弥散光晕（Dreamy Airbrush & Fluffy Pastel Texture）”美学的移动端尺寸互动疗愈 H5 应用。通过三步心境校准问卷，将用户引导至专属的引力场星球，伴随毛茸茸的白色小精灵漫步、聆听实时合成的治愈氛围乐与环境白噪音，并将心情化作星尘留在宇宙之中。

## 用户确认与关键决策

> [!IMPORTANT]
> 以下为根据您的偏好确认的核心交互与功能特性设计：

- **确认决策 1（听觉细节控制）**：在 4 个星球各自的 Web Audio API 多轨和弦氛围音乐基础上，加入专属的**环境白噪音叠加层**（如暖阳微风、林间晨雾、高空气流、静谧星海波纹）以及**柔和静音/白噪音混音开关**，同时在代码中预留外部 `<audio>` 音频文件路径替换接口。
- **确认决策 2（树洞星尘持久化）**：用户在树洞输入框放飞的心情文字将通过 `localStorage` 保存在本地浏览器中，不仅立即化作小精灵头顶的柔光云朵气泡并汇入当前背景星尘循环队列，下次重新开启漫游时依然会在星空中缓缓飘出。
- **确认决策 3（漫步手势与微互动）**：除底部左右方向按钮与屏幕两侧轻点外，支持**手指/鼠标左右滑动旋转星球**；点击毛茸茸的白色小精灵时，触发害羞眨眼、脸颊泛红加深或轻盈跃起并发出轻柔风铃泛音的趣味反馈。

## 1. 核心概念与体验总览

- **核心定位**：为疲惫或需要片刻喘息的用户提供一个 3～5 分钟的数字避风港。没有刺眼的几何边框与机械感指标，只有彩铅绘本般的颗粒肌理、流动的弥散光晕与温暖的毛绒陪伴。
- **目标场景**：工作间隙、会议刚结束、睡前放空或思绪繁杂时，戴上耳机进行的沉浸式微漫游。
- **核心价值**：将情绪评估（问卷）、视听疗愈（动态弥散光 + 生成式环境音）与轻度倾诉（星尘树洞）无缝串联，并以温暖的挥手告别完成情绪闭环。

## 2. 用户体验与视觉设计

### 关键用户流程（四幕剧结构）

1. **第一幕：开场引导页**
   - 画面中央柔焦弥散色块缓慢浮动，毛茸茸的白色小精灵轻轻呼吸起伏。
   - 呈现固定引导文案：“来这里短暂放松一下吧。为了获得更好的听觉陪伴，建议戴上耳机，把喧嚣留在门外。”
   - 点击底部毛玻璃柔光按钮 `[ 准备好了，开始短暂漫游 ]`，解锁 Web Audio 上下文并平滑淡入心境校准。
2. **第二幕：三步心境校准与曲速过渡**
   - 依次独立呈现 Q1、Q2、Q3 三道心境选择题，选项采用半透明磨砂柔光胶带质感，点击时伴有柔和微光扩散与轻巧音效。
   - 答完第 3 题后，进入 **1.5 秒曲速过渡动画**：背景色块柔和晕染交融至目标星球色系，浮现文案：“正在收集你散落的思绪…… 正在为你接通代号 [ 对应星球代号 ] 的引力场。”
3. **第三幕：星球漫步、坐下听歌与迷幻动态背景**
   - 画面中央偏下呈现边缘柔和羽化、带颗粒肌理的圆形星球，白色小精灵站在星球顶端。星球表面随角度分布着绘本风地标 **【🪑 聆听石】** 与 **【🌀 引力传送门】**。
   - 用户通过底部左右按钮、轻点屏幕左右侧或手指左右拖拽控制小精灵漫步（星球反向旋转）。
   - 当旋转至【🪑 聆听石】附近并点击 `[ 🪑 坐下听歌 ]` 时：
     - 小精灵切换为乖巧抱膝的“坐下”姿态。
     - 启动当前星球的 Web Audio 治愈和弦循环与环境白噪音。
     - 星球背后的多个大号柔焦色块（Blobs）启动呼吸般的流转、缩放与色相渐变动画。
     - 每隔 3.5 秒从星球背后的光晕中缓缓向上飘出半透明柔光星尘文字（包含 5 条内置治愈文案与用户历史放飞的心情）。
4. **第四幕：头顶气泡倾诉、传送门与挥手告别**
   - **树洞倾诉**：底部圆角柔光输入框支持写下心情并点击 `[ 放飞 ]`。正常输入时，小精灵头顶弹出云朵状柔光气泡展示 4 秒，并写入本地存储与背景星尘队列；若为空输入或纯空格，头顶弹出轻柔晃动的提示气泡：“气泡还是轻飘飘的呢，写两个字再放飞吧~”。
   - **引力传送门**：旋转至【🌀 引力传送门】或点击传送门按钮，弹出柔和面板：“去别的引力场看看吗？那里的风吹向另一片天空。”支持直接切换体验另外 3 个星球。
   - **右上角告别闭环**：点击右上角常驻按钮 `[ 👋 先去忙啦 ]`，音乐音量在 1.5 秒内平滑淡出；画面中央呈现两三只白色毛绒小精灵簇拥在一起、伸出圆手轻轻挥动拜拜的特写，浮现文字：“去忙吧，累了随时来找我，我会一直在这里等你。”底部提供 `[ 重新开启漫游 ]` 按钮重置状态回到第一幕。

### 视觉美学与色彩系统（Dreamy Airbrush & Fluffy Pastel Texture）

- **容器与视口规范**：
  - 遵循精确的手机竖屏比例容器（`max-width: 414px; height: 100vh; max-height: 860px; margin: 0 auto; border-radius: 28px; overflow: hidden; position: relative;`）。
  - 在电脑桌面端居中显示，容器外背景同步渲染低饱和度的同色系深邃环境柔光与柔和外发光阴影，消除突兀感；在手机端自动贴合全屏。
- **喷枪柔焦与彩铅噪点肌理**：
  - 全局顶层覆盖 `pointer-events: none` 的全屏 SVG `<feTurbulence>` 分形噪点滤镜图层（透明度 `0.075`），赋予所有渐变色块绘本彩铅与油画棒的细腻纸张颗粒感。
  - 严禁生硬几何边框；所有卡片、按钮、气泡均采用多层 `radial-gradient`、高斯模糊 `filter: blur(40px~70px)` 与内外柔光阴影（`box-shadow`）构建羽化边缘。
- **四颗星球的弥散光配色方案**：
  - **代号 Ω-01（琥珀暖阳，选 A ≥ 2）**：金黄麦浪色（`#FDE68A`）、暖阳橘（`#FDBA74`）、蜜桃粉（`#FBCFE8`）与柔和奶白（`#FFFBEB`）交织。
  - **代号 Δ-02（薄荷晨风，选 B ≥ 2）**：薄荷青绿（`#A7F3D0`）、嫩草绿（`#BBF7D0`）、柠檬微黄（`#FEF08A`）与晨雾白（`#F0FDF4`）交织。
  - **代号 Σ-03（晴空零度，选 C ≥ 2）**：纯净晴空蓝（`#BAE6FD`）、粉蓝云朵（`#E0F2FE`）、浅薰衣草紫（`#DDD6FE`）与柔白光晕（`#F8FAFC`）交织。
  - **代号 Ψ-04（静谧星海，A/B/C 各 1 平票）**：梦幻钴蓝（`#818CF8`）、暮光玫粉（`#F472B6`）、星尘暖黄（`#FDE047`）与深海柔和紫（`#4C1D95`）交织。
- **毛茸茸的白色小精灵（SVG + CSS 滤镜）**：
  - 使用 SVG `<filter id="fluffy-edge">`（结合 `feTurbulence`、`feDisplacementMap` 与多层柔光投影）绘制圆润蓬松的雪白毛绒团子。
  - 具备豆豆眼（带定时自然眨眼动画）、微小鼻尖、柔粉腮红，以及独立可控的四肢/姿态路径：支持 **漫步（walking，小脚交替轻点）**、**乖巧坐下（sitting，抱膝随音乐轻轻摇晃）**、**挥手告别（waving，多只小精灵簇拥挥手）** 以及 **轻点互动（happy bounce，害羞眨眼与微跳）**。

## 3. 核心产品决策与技术取舍

- **决策 1：Web Audio API 实时程序化音乐合成 + `<audio>` 外部音频双引擎架构**
  - *所选方案*：内置完整的 Web Audio API 多振荡器（正弦波/三角波和弦垫音 + 泛音琶音 + 滤波粉红/白噪音环境声）实时生成引擎，同时在配置对象中预留 `externalAudioUrl` 接口。若配置了外部音频 URL 则优先播放 `<audio>`，否则自动使用 Web Audio 合成器。
  - *原因*：确保应用在无外部音频文件依赖时也能即刻提供 4 段截然不同、温柔细腻且无缝循环的治愈音乐与自然白噪音，同时满足后续替换真实音频素材的扩展需求。
- **决策 2：基于角度坐标系的星球旋转与地标逼近检测**
  - *所选方案*：将星球建模为角度状态 `planetAngle`（0°～360° 循环），小精灵保持在星球正上方（0° 基准位），【🪑 聆听石】设置在 `45°`、【🌀 引力传送门】设置在 `-55°`（即 `305°`）。当用户旋转星球使地标进入顶部 `±22°` 感应区时，平滑浮现对应的互动提示与操作按钮。
  - *原因*：既保证了视觉焦点始终集中在画面中央的小精灵身上，又让左右漫步、拖拽旋转与寻找地标的过程具备真实的物理空间感。

### 核心数据模型与状态管理

- **`currentAct`**: `'intro' | 'quiz' | 'warp' | 'roaming' | 'farewell'` — 控制当前所处幕次与平滑过渡。
- **`quizAnswers`**: `('A' | 'B' | 'C')[]` — 记录用户在 3 道题中的选择，通过计票函数映射至 `'OMEGA_01' | 'DELTA_02' | 'SIGMA_03' | 'PSI_04'`。
- **`spiritState`**: `'idle' | 'walking' | 'sitting' | 'waving'` + `facing: 'left' | 'right'` + `isReacting: boolean` — 控制毛绒小精灵的 SVG 姿态与微互动反馈。
- **`audioState`**: `{ isPlaying: boolean, isMuted: boolean, whiteNoiseEnabled: boolean, activePlanetId: PlanetId }` — 管理音乐播放、白噪音开关与离开时的音量平滑淡出。
- **`stardustPool`**: `string[]` — 初始包含 5 条固定治愈文案，并与 `localStorage` 中的 `brief_roaming_user_stardust` 数组合并，当处于听歌状态时每 3.5 秒生成一个带随机水平偏移与柔光漂浮轨迹的星尘节点。

### 关键交互与状态映射

- **星球映射计算**：统计 `quizAnswers` 中 A、B、C 的频次：若 `count(A) >= 2` → `Ω-01（琥珀暖阳）`；若 `count(B) >= 2` → `Δ-02（薄荷晨风）`；若 `count(C) >= 2` → `Σ-03（晴空零度）`；若 `A === 1 && B === 1 && C === 1` → `Ψ-04（静谧星海）`。
- **漫步与坐下联动**：当用户点击左右移動或滑动星球时，若当前处于 `sitting`（坐下听歌）状态，小精灵可随时起身继续漫步，或点击 `[ 起身漫步 ]` 切换姿态；当移动到【🪑 聆听石】感应区内并点击 `[ 🪑 坐下听歌 ]` 时，`spiritState` 切换为 `'sitting'`，背景 Blobs 切换至流转呼吸动画类，启动星尘文字定时器与 Web Audio 治愈音轨。
- **树洞气泡与错误处理**：点击 `[ 放飞 ]` 时对输入字符串执行 `.trim()` 校验：
  - 若为空字符串：设置 `overheadBubble = { text: '气泡还是轻飘飘的呢，写两个字再放飞吧~', type: 'error' }`，触发柔和左右摇晃动画并在 3.5 秒后自动消散。
  - 若非空：设置 `overheadBubble = { text: cleanInput, type: 'normal' }` 持续显示 4 秒，同时将该句子追加至 `stardustPool` 及 `localStorage`，并在下一次星尘刷新时优先从背景飘出。
